# Distance_Calculator

## Description

This program calculates the distance between two points (x1, y1) and (x2, y2) on a cartesian coordinate plane

using input values and a math library.

## How to Run

1. Use any Compiler, or IDE.

2. Run the program.

3. Enter the coordinate values (x1, x2) and (y1, y2)

4. Check the distance displayed on the screen.

## Input Needed

- x1

- y1

- x2

- y2

## Sample Output

Enter x1: -6

Enter y1: 8

Enter x2: -3

Enter y2: 9

The distance between the two points is: 3.16
